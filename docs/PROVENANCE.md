# Implementation and provenance

This is a newly created, AI-assisted portfolio implementation of the proposed
ResearchGraph concept. It is not recovered code from a past employer or an earlier project.
Training, inference, data generators, APIs, dashboards and tests are included for
inspection. You should run the code, understand it and make your own changes before
presenting the work in interviews.

Source code and fixtures were authored for this repository. Pretrained third-party
weights and restricted datasets are not bundled. All default trained weights were
produced by the included scripts in the delivery environment. Library availability
and optional integrations are documented separately from executed checks.
